BSW

Bedrock-Server-Wrapper

BSWとは何をするためのもの？

BSWはBDS(Bedrock-Dedicated-Server)をNode.jsで管理・運用するための統合ツール！

ディスコードやWebダッシュボードで管理できるやつ！

機能紹介

  • サーバー管理・ログ収集

    • server.propertiesの一部の設定を.env で同期
    • チャットログ、死亡ログ、プレイヤー入退室ログ、ブロックの設置,破壊,TNTによる破壊ログ等を収集

  • バックアップ

    • 差分バックアップの自動実行
    • 1日/1回の自動フルバックアップ
    • プレイヤーがいないときのバックアップ停止や、退出時バックアップ
    • 指定日数で古いバックアップを自動削除

  • WebダッシュボードRESTAPIWebSocket

    • リアルタイムログの取得
    • コマンドを送信
    • 過去ログ、プレイヤーリスト、サーバー情報等を取得

  • Discord 連携

      チャットチャンネル専用

    • 双方向のチャット連携
    • プレイヤーリスト取得

      • 管理者チャンネル専用

    • 特定プレイヤーの現在の情報を取得(座標や持っているアイテム、HP、ゲームモードなど)
    • 過去10件の死亡履歴取得(座標付き)
    • BAN、BAN解除等の処理(期限付きも可能)
    • 手動でバックアップ実行
    • バックアップからのリストア
    • ブロック破壊、設置、TNTによる破棄のログを取得(フィルター付き)
